Blink SIP and WebRTC client
---------------------------

Blink is an easy to use multimedia SIP and WebRTC client.

 * Clear audio using Opus codec optimized for wideband voice calls
 * Stereo Opus podcasting with third-party streaming apps
 * Classic telephony support (codecs, call transfer, DTMF)
 * One to one video calling (of course)
 * WebRTC video conferencing (using sip2sip.info or a dedicated SylkServer)
 * Offline messaging and file transfers (using sip2sip.info or a dedicated SylkServer)
 * Instant Messaging (SIP Message)
 * Chat, File Transfers and Conferencing sessions (MSRP protocol) 
 * Fine-grained settings for SIP experts

Blink does not collect any data. Contacts accessed by Blink from system address-book are not uploaded to any servers.
